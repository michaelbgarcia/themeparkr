# CLAUDE.md

## Overview

`themeparkr` is a small R package wrapping the public ThemeParks API (https://api.themeparks.wiki, docs at https://themeparks.wiki/). No auth is required.

## Commands

Run from the repo root in R. `.Rprofile` activates renv (`snapshot.type: all`, so `renv.lock` also pins dev tools); run `renv::snapshot()` after adding a dependency. `Rscript --vanilla` skips renv and uses the user library.

```r
devtools::document()   # regenerate NAMESPACE and man/*.Rd
devtools::test()       # offline tests against recorded API responses
devtools::test(filter = "tpr_entity_children")  # single test file
devtools::check()      # examples are @examplesIf interactive(), so no network needed
```

Tests never hit the network: `local_fixture("name")` (`tests/testthat/helper-fixtures.R`) mocks `tpr_fetch()` to return `tests/testthat/fixtures/name.json`. Tests of `tpr_fetch()` itself use `httr2::local_mocked_responses()`. To cover a new API shape, save a trimmed real response there with `curl`.

## Architecture

One exported function per file in `R/`, each mapping to one API endpoint: build the path with `glue`, call the internal `tpr_fetch(path, task)` (`R/utils-fetch.R`; HTTP errors become a `themeparkr_http_error` reported against the calling exported function), then flatten the nested list into a plain tibble with purrr/dplyr/tidyr.

Gotchas:
- The API sometimes omits `location` or sends null coordinates, and many fields are optional; use `tpr_location()` and `pluck(.default = NA)` rather than assuming fields exist.
- In `tpr_entity_children`, the input `id` must be injected as `!!id` inside `mutate()`, since children have their own `id` column.

## Conventions

- `NAMESPACE` and `man/` are generated by roxygen2; edit the roxygen tags in `R/*.R` and run `devtools::document()`, never edit them by hand. Any new package dependency must also be added to `Imports:` in `DESCRIPTION`.
- Code uses `=` for assignment and `pkg::fn()` qualified calls; the only `@importFrom` is magrittr's `%>%` (`R/utils-pipe.R`).
- Bump `Version:` in `DESCRIPTION` and add an entry to `NEWS.md` when changing output shape.
- `inst/scratch/` is a gitignored local prototyping scratchpad, not package code.
